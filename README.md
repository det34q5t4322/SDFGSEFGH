# 🎓 Расписание Колледжа телекоммуникаций + Telegram-бот

Современный, быстрый и красивый веб-сервис для просмотра расписания занятий колледжа с интеграцией в Telegram (включая Telegram Mini App) и **гарантированным решением проблемы блокировок Telegram API на серверах в РФ**.

---

## 🌟 Возможности проекта

1. **Автоматическая синхронизация с Google Таблицей**:
   - Парсит данные напрямую из вашей таблицы: 77 учебных групп, 6 дней, по 6 пар.
   - Автоматически распознает **Числитель (I)** и **Знаменатель (II)** недели.
   - Разделяет предметы, ФИО преподавателей и номера кабинетов.
   - Интеллектуальное кэширование (обновление каждые 15 мин без лишних запросов к Google).
2. **Премиальный веб-интерфейс**:
   - Адаптивный дизайн (Mobile First) с тёмной и светлой темами.
   - Быстрый выбор группы с поиском и фильтром по курсам (1–4 курсы, Очно-заочное).
   - Вкладки «Сегодня», «Завтра», «Вся неделя».
   - **Живой индикатор текущей пары**: показывает, какая пара идет прямо сейчас и сколько минут осталось до звонка.
   - Поиск по преподавателям (где и у кого сейчас ведет пару преподаватель).
   - Поиск по аудиториям (занятость кабинетов).
   - Сохранение любимой группы в избранное (не нужно выбирать заново).
3. **Telegram-бот + Telegram Mini App (TMA)**:
   - Кнопка **«📱 Открыть расписание»** прямо в Telegram (открывает полноценное веб-приложение внутри мессенджера).
   - Текстовые команды: `/today`, `/tomorrow`, `/week`, `/group`.
   - Инлайн-меню выбора группы по курсам.
4. **🛡️ 100% обход блокировок Telegram на серверах в России**:
   - Встроенная поддержка бесплатного проксирования через **Cloudflare Worker** (2 минуты настройки, бесплатно навсегда).
   - Поддержка обычных SOCKS5/HTTP прокси.

## 🚀 Быстрый старт на сервере в РФ

### Шаг 1. Создание бесплатного Cloudflare Worker (для обхода блокировки)

> **Зачем это нужно?**  
> На большинстве хостингов в РФ (Timeweb, Selectel, Beget, VK Cloud и др.) прямые запросы к `api.telegram.org` заблокированы или режутся ТСПУ. Cloudflare Worker выступает надежным и быстрым мостом:  
> `Ваш сервер в РФ` ➔ `Cloudflare Worker` ➔ `api.telegram.org`.

1. Зарегистрируйтесь на сайте [dash.cloudflare.com](https://dash.cloudflare.com/) (бесплатно, иностранные карты не требуются).
2. В левом меню перейдите в раздел **Compute (Workers) > Workers & Pages**.
3. Нажмите кнопку **Create application** ➔ **Create Worker**.
4. Укажите любое имя (например, `tg-bot-proxy`) и нажмите **Deploy**.
5. Нажмите кнопку **Edit code**.
6. Сотрите всё и вставьте содержимое файла [`cf-worker/worker.js`](./cf-worker/worker.js).
7. Нажмите **Deploy**.
8. Скопируйте полученный адрес воркера (например: `https://tg-bot-proxy.yourname.workers.dev`).

---

### Шаг 2. Создание бота в @BotFather

1. Откройте Telegram и найдите бота [@BotFather](https://t.me/botfather).
2. Отправьте команду `/newbot` и задайте имя и юзернейм (например, `TelecomCollegeScheduleBot`).
3. Скопируйте полученный **HTTP API Token**.
4. *(Опционально, для кнопки Mini App)*:
   - В @BotFather отправьте `/newapp`, выберите созданного бота.
   - Укажите название, описание, загрузите картинку (640x360).
   - В поле URL укажите адрес вашего сайта (например, `https://schedule.yourdomain.ru`).
   - Задайте короткое имя (short name). Теперь WebApp доступен по ссылке `t.me/YourBot/app`!

---

### Шаг 3. Настройка окружения на сервере

Склонируйте проект и перейдите в папку:
```bash
git clone <url-вашего-репозитория>
cd college-schedule-app
```

Создайте файл `.env` на основе примера:
```bash
cp .env.example .env
nano .env
```

Заполните переменные:
```ini
# Токен бота из @BotFather
BOT_TOKEN=123456789:AAH...

# Адрес вашего сайта (если уже привязали домен)
WEB_APP_URL=https://schedule.yourdomain.ru

# Ссылка на созданный Cloudflare Worker (добавьте /bot в конце!)
TELEGRAM_API_URL=https://tg-bot-proxy.yourname.workers.dev/bot

# Порт веб-сервера
PORT=8000
```

---

### Шаг 4. Запуск

#### Вариант А: Через Docker Compose (Рекомендуется)
```bash
docker compose up -d --build
```
Все процессы (веб-сайт и Telegram-бот) запустятся автоматически и будут перезапускаться при перезагрузке сервера.

#### Вариант Б: Прямой запуск через Python
```bash
# Установка зависимостей
pip install -r requirements.txt

# Единый запуск сайта и бота
python server/run_all.py
```

## 📡 REST API Эндпоинты

- `GET /` — Главная страница веб-расписания.
- `GET /api/status` — Метаданные (название семестра, время последнего обновления, число групп).
- `GET /api/groups` — Список всех 77 групп, сгруппированных по курсам.
- `GET /api/schedule?group=ИСП9-24А` — Расписание конкретной группы по всем дням недели.
- `GET /api/teachers` — Список всех преподавателей колледжа.
- `GET /api/teacher-schedule?teacher=ФИО` — Расписание пар конкретного преподавателя.
- `GET /api/classrooms` — Список всех аудиторий.
- `GET /api/classroom-schedule?room=218` — Занятость кабинета по дням недели.
- `POST /api/refresh` — Принудительная синхронизация с Google Таблицей.
